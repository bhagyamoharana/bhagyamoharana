## 📊 Research Highlights  

- **Collaborative VR Studies**: Built Unity prototypes where remote users solved shared tasks while wearing physiological sensors (EDA, HR, Eye-tracking).  
- **Linear Regression Models**: Used regression to predict:  
  - How **physiological synchrony** affects **task completion time**  
  - How **pupil dilation & HR synchrony** correlate with **perceived workload**  
  - How **positive vs. negative sentiment** in voice predicts collaboration outcomes  
- **Data Analysis Pipelines**: Developed Python/R scripts to clean multimodal datasets (physiology + voice + task metrics) and run regression + correlation models.
